# Product Marketing Context — SystemPrompts.fun

## What is SystemPrompts.fun?

SystemPrompts.fun is a **free, public database of verified LLM system prompts** from the world's most popular AI coding assistants and tools. The prompts are reverse-engineered from production AI tools and published for educational purposes.

## Mission

Transparency in AI. Developers deserve to understand the exact instructions powering the AI tools they use every day.

## Target Audience

- **Primary**: Software developers (frontend, backend, full-stack) using AI coding tools
- **Secondary**: AI researchers, prompt engineers, tech-curious builders
- **Tertiary**: Students learning about AI and LLMs

## Key Value Propositions

1. **Free access** to verified system prompts — no paywall, no signup
2. **50+ tools** including Cursor, Claude Code, GitHub Copilot, v0, Lovable, Windsurf, Devin, Replit, and more
3. **Verified accuracy** — prompts are reverse-engineered and cross-checked
4. **Educational** — learn prompt engineering by studying real production prompts
5. **Up to date** — prompts are updated as tools evolve

## SEO Strategy

### Target Keywords (Primary)
- "system prompt [tool name]" (e.g. "cursor system prompt", "claude code system prompt")
- "what is [AI term]" (e.g. "what is a system prompt", "what is an LLM")
- "best AI tools for [persona]" (e.g. "best AI tools for frontend developers")
- "AI for [use case]" (e.g. "AI for code review")
- "[tool] vs [tool]" (e.g. "cursor vs windsurf")

- `/tool/[id]` — Individual tool prompt pages (50+ pages)

- `/for/[persona]` — Persona landing pages (10+ personas) ← NEW

## Tone & Voice

- **Technical but accessible** — developers appreciate precision
- **Neutral / educational** — we present facts, not marketing copy
- **No hype** — direct, informative, honest
- **Slightly mysterious** — the "archive / transmissions" theme adds personality

## Conversion Goals

1. Users explore and copy system prompts (primary engagement metric)
2. Users share the site (word of mouth growth)
3. Future: newsletter signup, premium features
